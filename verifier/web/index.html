Provably-Fair Verifier

Recomputes the uniform random stream behind a bet from its revealed seeds — bytes = HMAC_SHA256(serverSeed, "clientSeed:nonce:cursor"), float = uint32(bytes[0..4], big-endian) / 2³² — the exact derivation the server runs (engine/src/engine/rng.py).

This page reproduces the shared float stream (the load-bearing primitive). The per-game mapping from those floats to a payout lives in the Python reference (verifier/), which imports the server's engine/ verbatim — that module is the authoritative, parity-guaranteed verifier. For Crash round mode, set clientSeed = roundId and nonce = roundNumber (cursor 0).
